# Security Policy

## Supported Versions

Only the latest stable release of bbGuild - World of Warcraft is supported with security
updates.

## Reporting a Vulnerability

Do not open a public GitHub issue or pull request for security
vulnerabilities.

Instead, use [GitHub's private vulnerability reporting](https://github.com/avatharbe/bbguildwow/security/advisories/new)
or email **info@avathar.be** with:

- A description of the vulnerability and its potential impact
- Steps to reproduce it (a minimal proof of concept, if possible)
- Any suggested fix, if you have one

You can expect an initial response within a few days. Once a fix is
confirmed, it will be released as soon as practical, and you'll be
credited in the release notes unless you prefer to remain anonymous.
